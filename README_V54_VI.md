# Web V54 — Flash V110 và các nhánh cũ

Chép index.html lên GitHub Pages thay file hiện có. Giao thức 110 có thêm mặt Lịch trái · giờ lớn. Firmware109 không hiện mặt mới. Giữ các chức năng AHT30 đến V56, tải ảnh và thanh chờ chuyển mặt.

Sau khi nạp V110, bấm Cài tài nguyên để thay gói bổ sung thành 2603 byte. Gói chính hợp lệ sẽ được bỏ qua. Không cài gói mới vào firmware109 hoặc AHT30: web nhận diện và chọn gói riêng.

Chưa triển khai lên GitHub và chưa thử Bluetooth thật/Bluefy.
